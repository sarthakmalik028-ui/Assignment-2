# Assignment-2

Task 1:This program checks whether a number entered by the user is odd or even.
Prompts the user to enter a number.

Converts the entered value into an integer.

Uses a condition to check the remainder when the number is divided by 2.

If the remainder is not zero, it identifies the number as odd.

If the remainder is zero, it identifies the number as even.

Displays the result indicating whether the number is odd or even.





Task 2:This program calculates the sum of numbers from 0 to 50 (which effectively gives the sum from 1 to 50 since adding 0 does not change the total).
Initializes a variable to store the total sum and sets it to zero.

Uses a loop to go through numbers from 0 up to 50.

Adds each number in the sequence to the total during every loop iteration.

Continuously updates the total as the loop progresses.

After completing the loop, displays the final sum of numbers from 1 to 50.
